# Changelog

## [Unreleased]

- Initial scaffold: framework-agnostic core (Contracts, DTOs, Enums, StatusNormalizer, CarrierRegistry, ShippingManager, FakeDriver) + Laravel service provider stub + Pest test skeleton.
- Native Bosta driver (`src/Drivers/Bosta/`: BostaClient, BostaDriver, BostaPayloadFactory, DeliveryType) with create/track/label/cancel, return (CRP 25) + exchange (30) via create payload, COD + webhooks, raw `Authorization` API-key auth, sandbox/production hosts, and Pest coverage via injectable `Http\Factory::fake()`.
- Native Aramex driver (`src/Drivers/Aramex/`: AramexSoapClient, AramexDriver, AramexPayloadFactory) for Shipping API V2 over raw SOAP 1.1 via injectable `Http\Factory` (no `ext-soap`): CreateShipments (Shipper/Consignee/ShipmentDetails with ProductGroup/ProductType/PaymentType/COD via CODS), TrackShipments, PrintLabel, CalculateRate; cancellation honestly disabled (V2 has pickup-cancel only, no shipment-cancel); Pest coverage via canned SOAP XML.
- Native Mylerz driver (`src/Drivers/Mylerz/`: MylerzClient, MylerzDriver, MylerzPayloadFactory) modeled on `mohamedhekal/shipbridge-mylerz` source (AddOrders → `Packages[0].BarCode`, `GetPackageListStatus`, `GetAWB`, `/token` password-grant Bearer auth); create/label/track + return/exchange via `metadata.service_category` + COD; rates/webhooks honestly `false`; Pest coverage via `Http\Factory::fake()`.
- Native Egypt Post tracking-only driver (`src/Drivers/EgyptPost/`: EgyptPostClient, EgyptPostDriver) modeled on `mohamedhekal/shipbridge-egyptpost` `track_only` mode (official TrackTrace `GetShipmentDetails` for `track()`; `label()` returns the public tracking URL with empty contents); `createShipment`/`createReturn`/`createExchange` throw `ShippingException::unsupportedOperation`; capabilities `track=true`, everything else `false`.
- Native SMSA Express driver (`src/Drivers/Smsa/`: SmsaSoapClient, SmsaDriver, SmsaPayloadFactory) modeled on `mohamedhekal/shipbridge-smsa` + live SECOM WSDL (`addShip`/`getTrack`/`getStatus`/`getPDF`/`cancelShipment` verified): raw SOAP 1.1 XML over injectable `Http\Factory` (no `ext-soap`; SimpleXML parsing), per-connection `passkey` auth, create/track (getTrack with getStatus fallback)/label/cancel + return/exchange via `metadata.ship_type` (`RET`/`DLV`) + COD; rates/pickup/webhooks honestly `false`; Pest coverage via `Factory::fake()` with canned SOAP XML (success + Fault).
- Native DHL Express driver (`src/Drivers/Dhl/`: DhlClient, DhlDriver, DhlPayloadFactory) modeled on `sonnenglas/mydhl-php-sdk` (spec 3.3.1: Basic Auth + `Message-Reference`/`x-version` headers, `GET /rates` one-piece + `POST /rates` multi-piece with BILLC price parsing, `POST /shipments`, `GET /shipments/{id}/tracking` with `requestGMTOffsetPerEvent`), confirmed by `korbeil/dhl-express-php-api` (BasicAuth + production/test hosts) and structured like `mohamedhekal/shipbridge-dhl` (Client/PayloadFactory/Driver split, tracking batch fallback): per-connection HTTP Basic auth (no OAuth2/token flow exists for MyDHL — `cacheKey()` intentionally unused), rates/create/track only; label honestly disabled (no label endpoint — transport label is inline at creation and preserved in `raw.label_contents`), return/exchange/COD/cancel/webhooks honestly `false`; Pest coverage via `Factory::fake()`.
- Native FedEx REST driver (`src/Drivers/Fedex/`: FedexClient, FedexDriver, FedexPayloadFactory) modeled on `mohamedhekal/shipbridge-fedex` payload/response shapes (`transactionShipments`/`masterTrackingNumber`, `completeTrackResults`/`scanEvents`/`derivedStatusCode`, `packageDocuments`/`encodedLabel`) with endpoint/field authority from `WhatArmy/FedexRest` (`/oauth/token` form, `/ship/v1/shipments`, `/rate/v1/rates/quotes`, `/track/v1/trackingnumbers`, `labelResponseOptions=LABEL`); `ShipStream/fedex-rest-sdk` inspected but not adopted (Saloon dependency): per-connection OAuth2 client_credentials memoized per client instance via `connection->cacheKey('fedex')` (same pattern as sibling UpsClient, never global; pre-issued `token` skips OAuth), create/rates/track + return/exchange via swapped-parties ship payload + COD via `shipmentSpecialServices`; label bytes preserved in `raw` and reused by `label()` (fixes the shipbridge-fedex gap where `label()` returned only a tracking URL), else tracking-URL fallback; cancel/pickup/webhooks honestly `false`; Pest coverage via `Factory::fake()`.
- Native UPS REST driver (`src/Drivers/Ups/`: UpsClient, UpsDriver, UpsPayloadFactory) with OAuth2 client-credentials auth (Basic `client_id`:`client_secret` → Bearer, `onlinetools.ups.com` live / `wwwcie.ups.com` CIE) — legacy gabrielbull AccessKey+UserID+Password XML auth intentionally unsupported (UPS is migrating to OAuth2 REST); field knowledge reused from `gabrielbull/php-ups-api` (Service/PackagingType codes, prepaid BillShipper payment, Package weight/dimensions, COD options, NegotiatedRates) reshaped into the `mohamedhekal/shipbridge-ups` REST envelopes (`ShipmentRequest`, `transId`/`transactionSrc`, `PackageResults`/`TrackingNumber`/`GraphicImage`, `trackResponse.shipment.package.activity`); per-connection token memoized per client instance via `connection->cacheKey('ups')` (same pattern as sibling FedexClient, never global; pre-issued `token` skips OAuth); create (one-call Ship, charges + label bytes preserved in `raw`) / `Shop` rates (multi-service `RatedShipment` quotes with `GuaranteedDelivery`) / track (activities + `currentStatus` fallback, not-found mapped to `shipmentNotFound`) / label via `POST /api/labels/{v}/recovery` returning real `GraphicImage` bytes (fixes the shipbridge-ups tracking-URL-only gap) + `extractLabelContents()` for stored `raw` / void-cancel via `DELETE /api/shipments/{v}/void/cancel/{id}` (OpenAPI + CIE evidence) + COD; return/exchange/pickup/webhooks/customs honestly `false`; Pest coverage via `Factory::fake()` (token, create+label bytes, rates, track, label recovery, void, per-connection tokens, capabilities, sanitization).
